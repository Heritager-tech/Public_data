  FLOATING SHAPES — Инструкция по переиспользованию
  Файл: FloatingShapes.tsx
═══════════════════════════════════════════════════════════════════

ЧТО ЭТО:
  Фиксированный фоновый эффект — голубая сетка + белые плавающие
  геометрические фигуры (квадраты, круги, гексагоны, треугольники,
  ромбы, точки) + соединительные линии между ними.
  Эффект остаётся на месте при прокрутке страницы.

КАК ДАТЬ ЭТО AI ДЛЯ ПОВТОРНОГО ИСПОЛЬЗОВАНИЯ:
  Отправьте AI следующее сообщение:

  ─────────────────────────────────────────────────────────────
  «Прикрепляю файл FloatingShapes.tsx — это эффект плавающих
  геометрических фигур на фиксированном фоне. Добавь его на мой
  сайт как фоновый слой. [опишите цвет/стиль адаптации если нужно]
  Файл: [прикрепить FloatingShapes.tsx]»
  ─────────────────────────────────────────────────────────────

  AI прочитает конфиг в начале файла и адаптирует под ваш дизайн.

КАК ИНТЕГРИРОВАТЬ ВРУЧНУЮ:

  1. Скопировать FloatingShapes.tsx в папку компонентов

  2. Добавить CSS в глобальные стили:

     .floating-shapes-canvas {
       position: fixed;
       top: 0; left: 0;
       width: 100%; height: 100%;
       pointer-events: none;
       z-index: 2;
     }
     @media (prefers-reduced-motion: reduce) {
       .floating-shapes-canvas { opacity: 0.4; }
     }

  3. Импортировать и добавить в корень страницы:

     import FloatingShapes from '@/components/FloatingShapes';

     <main>
       <FloatingShapes />   ← добавить первым дочерним элементом
       ...остальной контент...
     </main>

  4. Сделать фоны секций полупрозрачными (opacity ~88-95%),
     чтобы фигуры просвечивали сквозь контент.

АДАПТАЦИЯ ПОД ДИЗАЙН (менять в объекте CONFIG в начале файла):

  ТЁМНЫЙ САЙТ (по умолчанию):
    Оставить как есть — белые фигуры, голубая сетка

  СВЕТЛЫЙ САИТ:
    GRID_COLOR = 'rgba(0, 0, 0, 0.06)'
    CONN_COLOR_BASE = [0, 0, 0]
    Изменить цвет фигур в animate():
      ctx.strokeStyle = `rgba(0, 0, 0, ${shape.opacity})`
      ctx.fillStyle = `rgba(0, 0, 0, ${shape.opacity})`

  БРЕНДОВЫЙ ЦВЕТ (например teal #14b8a6):
    GRID_COLOR = 'rgba(20, 184, 166, 0.12)'
    CONN_COLOR_BASE = [20, 184, 166]

  БЕЗ СЕТКИ:
    GRID_SPACING = 0

  БЕЗ СОЕДИНИТЕЛЬНЫХ ЛИНИЙ:
    CONN_MAX_DIST = 0

  ГУЩЕ/РЕЖЕ:
    SHAPE_DENSITY = 10000 (гуще) или 35000 (реже)

  ДРУГИЕ ФИГУРЫ:
    Изменить SHAPE_WEIGHTS — уменьшить вес типа чтобы он
    встречался реже, или добавить новый тип в switch drawShape()
